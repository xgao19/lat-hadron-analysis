# Example EMFF n-state fit control file
# Lines starting with # are comments, blank lines are ignored.

#   title_pattern Ns Nt a_fm
#
# Key parameters:
#   c2pt              - path pattern to 2pt HDF5 files (use {src_gamma})
#   c3pt_h5           - three-point HDF5 file path/glob template
#   c3pt_dataset_path - three-point HDF5 dataset path template
#   src_gamma         - source gamma matrix (matches the 2pt HDF5 file name)
#   sink_gamma        - sink gamma matrix under SS/ in the 2pt HDF5 file
#   insert_gamma      - current insertion gamma (T for vector current)
#   nstates           - number of states (1 and/or 2)
#   pflist            - final momentum Pf: pfx pfy pfz
#   qxlist/qylist/qzlist - momentum transfer values (or qxrange/qyrange/qzrange)
#   average_transverse_orbits - average degenerate transverse q sign/exchange orbits
#   tslist            - time separation values (or tsrange_emff for range)
#   fit_method        - "2state", "summation", or "plateau"
#   hadron_mass_gev   - hadron mass used in the ratio dispersion relation
#   ratio             - Eq. (6) of arXiv:2102.06047
#   tau_range         - tau window: tau_min tau_offset (-1 means tsep-1)
#   tsep_range        - tsep window for fitting: tsep_min tsep_max
#   binsize           - binning size before bootstrap
#   bootstrap_samples - "auto" or integer number of bootstrap samples
#   seed              - random seed for bootstrap
#   two_point_fit_root         - root directory for 2pt nstate fit results
#   two_point_fit_window_by_pz - path to 2pt fit window table
#   plot              - whether to generate plots (true/false)
#   results_dir       - output directory
